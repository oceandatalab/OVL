# Jupyter notebooks examples

with their outputs, so you can read them without running anything.

| Notebook | What it does |
| --- | --- |
| **[Plot data extracted from the OVL portal](../notebooks/ovl-portal/plot_ovl_extraction.ipynb)** | Plot an extracted numpy object. |
| **[SAR image spectra from the OVL portal](../notebooks/ovl-portal/S1_swell_from_OVL.ipynb)** | Perform a spectrum on an extracted SAR Sentinel-1 data. |
