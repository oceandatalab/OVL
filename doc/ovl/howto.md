# Typical user workflow

This section walks through common tasks with short video tutorials, showing
how to combine the tools described in [Individual features](features.md).

## Search, collocate and select products

Find the datasets you need in the catalogue, on the left, using the filter
icon or the preselected tags, and tick them to add them to the
[Display data panel](features.md#the-display-data-panel). Turn on
[collocation](features.md#collocation) so the timeline only highlights the
dates where all your selected products are available together.

## Play with time and timespan

Pick a timespan — from **1-Hour** to **Bi-weekly** — to set the window data is
searched for, then move through the available dates on the timeline. Open the
detailed timeline to see exactly where the granules of each dataset sit within
that window.

## Compare different layers

Once several layers are selected, use the
[Display data panel](features.md#the-display-data-panel) to reorder them by
drag and drop, and scroll on the transparency wheel of the layer on top to
reveal the one underneath.

## Draw and analyse a synoptic chart

Use the [drawing tools](features.md#drawing-a-shape) to place points, arrows,
polylines, polygons, eddies, mushrooms or text over the features you want to
annotate, then open the edit panel to style them, read the computed metrics —
such as the length of a polyline — and export the result.
