# Download and install

## Linux

* Download the compressed archive from SEAScope website [seascope-viewer-20250709.tar.gz](https://seascope.oceandatalab.com/viewer/seascope-viewer-20250709.tar.gz)
* Move the archive to the proper location on your computer
* Uncompress the archive: a directory named seascope is created

Instructions are available also on our YouTube video:
[![How to Install SEAScope on Linux](https://img.youtube.com/vi/2DuqY6s1JZk/mqdefault.jpg)](https://youtu.be/2DuqY6s1JZk?si=jGfDPOnXKfl7o07y)

▶ [How to Install SEAScope on Linux](https://youtu.be/2DuqY6s1JZk?si=jGfDPOnXKfl7o07y)

## macOS

* Download the disk image from SEAScope website [SEAScope-viewer-20250709.dmg](https://seascope.oceandatalab.com/viewer/seascope-viewer-20250709.dmg).
* Drag SEAScope to the Applications folder
