# The SEAScope application

<a href="https://seascope.oceandatalab.com"><img src="../../images/seascope-logo.png" alt="SEAScope" width="90" align="right"></a>

SEAScope is a standalone 3D visualisation and analysis application for satellite,
in-situ and numerical model data. Its rendering is designed to ease the detection
of synergies between several sources of observations and simulations, without the
complications introduced by map projections. An optional Python package allows the
viewer to be controlled remotely and data to be exchanged with a Python session or
a Jupyter notebook.

SEAScope runs on Linux, macOS and Windows, and is available from
<https://seascope.oceandatalab.com>
