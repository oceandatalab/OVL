# OVL

Ocean Virtual Laboratory resources, maintained by
[OceanDataLab](https://www.oceandatalab.com).

This repository holds the user manual for the three tools we develop for the
joint exploration of satellite, in-situ and model ocean data. You can read the
whole manual directly on GitHub — start at **[the manual index](doc/index.md)**, or
jump straight to a chapter:

| Chapter | What it covers |
| --- | --- |
| **[OVL portal](doc/ovl/index.md)** | The web portal for discovering and jointly handling co-located Earth observation datasets in your browser. |
| **[SEAScope](doc/seascope/index.md)** | The standalone 3D visualisation and analysis application, with an optional Python interface for quantitative analyses and scripted interactions. |
| **[SEAShot](doc/seashot/index.md)** | The tool for capturing, previewing and sharing stories and test cases from the OVL portal. |

## What is in this repository

| Path | Contents |
| --- | --- |
| **[`doc/`](doc)** | The user manual — one directory per tool. |
| **[`notebooks/`](notebooks)** | Runnable Jupyter examples, under [`ovl-portal/`](notebooks/ovl-portal) and [`seascope/`](notebooks/seascope). |
| `images/` | Logos and figures used by the manual. |
| `myst.yml` | Configuration and table of contents for the published site. |


## Asking a question or reporting a bug

Open an [issue](https://github.com/oceandatalab/OVL/issues) — for questions about
using the tools as well as for bugs. When reporting a bug, please say which tool
you were using, what you expected, and what happened instead.

You can also reach us at <https://www.oceandatalab.com/contact>.
